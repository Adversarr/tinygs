# Dataset Module

The dataset module handles loading images and camera parameters from various sources.

## Files

| File | Description |
|------|-------------|
| `dataset.hpp` | Base class and data structures |
| `image.hpp` | Image dataset backed by `cameras.json` + `poses.json` |

---

## Dataset Types

| Type | Description | Use Case |
|------|-------------|----------|
| `image` | JSON camera + image folder dataset | Converted COLMAP/NeRF datasets |

## Data Structure

```cpp
struct Data {
    Image image;         // RGB image (UInt8 CHW-tiled, pinned host memory)
    mat4x4 w2c;         // World-to-camera matrix
    mat3x3 K;           // Intrinsic matrix
    uuid_t cam_uid;     // Camera ID (0-based)
    uuid_t frame_idx;   // Frame ID (1-based)
    uuid_t timestamp;   // Unique timestamp identifier
};
```

## DatasetBase Interface

```cpp
class DatasetBase {
public:
    /// @brief Load dataset from disk
    virtual void load() = 0;
    
    /// @brief Configuration
    virtual void set_params(const json& params);
    virtual json get_params() const;
    
    /// @brief Number of frames
    virtual size_t size() const noexcept = 0;
    
    /// @brief Image dimensions
    virtual ImageShape image_shape() const = 0;
    
    /// @brief Access frame by index
    virtual Data operator[](size_t idx) const = 0;
    
    /// @brief Camera loader access
    SingleCameraLoader& get_camera_loader();
};
```

## Image Dataset

Loads images from `root_path/images` with camera metadata from
`root_path/cameras.json` and `root_path/poses.json`.

### Configuration

```json
{
    "type": "image",
    "root_path": "outputs/scene/train/",
    "extension": "png",
    "resolution": -1,
    "resolution_scale": 1.0
}
```

| Parameter | Type | Description |
|-----------|------|-------------|
| `root_path` | string | Path containing `cameras.json`, `poses.json`, and `images/` |
| `extension` | string | Image extension (`png`, `jpg`) |
| `resolution` | int | `{1,2,4,8}` divisor, `-1` auto(1600 cap), `>0` target width |
| `resolution_scale` | float | Additional divisor scale |

### Metadata Format

`ImageDataset` expects JSON metadata generated by
`convert_mipnerf360_to_data_storage.py`:

- `cameras.json`: array of camera intrinsics (`camera_id`, `model`, `width`, `height`, `params`)
- `poses.json`: array of frame poses (`image_id`, `camera_id`, `name`, `qvec`, `tvec`)

Images are loaded from `root_path/images/<name>` where `<name>` comes from `poses.json`.

## Creating a Dataset

```cpp
// Via factory
auto dataset = create_dataset("image");

// Configure
dataset->set_params({
    {"root_path", "outputs/scene/train/"},
    {"extension", "png"},
    {"resolution", -1},
    {"resolution_scale", 1.0f}
});

// Load from disk
dataset->load();

// Access data
size_t num_frames = dataset->size();
Data frame0 = (*dataset)[0];
Image image = frame0.image;
mat4x4 w2c = frame0.w2c;
mat3x3 K = frame0.K;
```

## Camera Model

```cpp
enum class CameraModel {
    Pinhole,   // Standard pinhole camera
    Fisheye    // Fisheye camera (with distortion)
};

struct CameraIntrinsics {
    int id;
    CameraModel model;
    int width, height;
    float fx, fy;   // Focal length
    float cx, cy;   // Principal point
};
```

---

## Camera Extrinsics

```cpp
struct CameraExtrinsics {
    quat rotation;      // Orientation quaternion (w, x, y, z)
    vec3 translation;   // Position in world coordinates
    uint64_t cam_id;
    uint64_t frame_id;
    
    mat4x4 get_w2c() const;  // World-to-camera matrix
    mat4x4 get_c2w() const;  // Camera-to-world matrix
};
```

## SingleCameraLoader

Manages camera intrinsics and extrinsics:

```cpp
class SingleCameraLoader {
public:
    void load_from_json(const std::string& cameras_json_path,
                        const std::string& poses_json_path);
    
    const std::vector<CameraIntrinsics>& get_camera_intrinsics() const;
    const std::vector<CameraExtrinsics>& get_camera_extrinsics() const;
    
    void resize_sensor(uint32_t width, uint32_t height);
};
```

## Usage Example

```cpp
// Create and configure dataset
auto train_dataset = create_dataset("image");
train_dataset->set_params({
    {"root_path", "data/train/"},
    {"extension", "png"},
    {"resolution", -1},
    {"resolution_scale", 1.0f}
});
train_dataset->load();

// Create test dataset (optional)
auto test_dataset = create_dataset("image");
test_dataset->set_params({
    {"root_path", "data/val/"},
    {"extension", "png"},
    {"resolution", 2},
    {"resolution_scale", 1.0f}
});
test_dataset->load();

// Create dataloaders
auto train_loader = create_dataloader("async", train_dataset);
auto test_loader = create_dataloader("simple", test_dataset);
```
